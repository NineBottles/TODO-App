# Tika (Ticket + Kanban) — PRD

## 1. 제품 개요

Tika는 **티켓 기반 칸반 보드 To-do App**입니다. 사용자는 할일을 "티켓" 단위로 등록하고, 칸반 보드 위에서 상태(칼럼)를 이동시키며 진행 상황을 관리합니다. 개인용 할일 관리를 목표로 하며, 계획 대비 실제 진행 일정을 추적할 수 있는 것이 특징입니다.

## 2. MVP 범위

- **단일 사용자** 전용 (인증 없이 사용)
- **고정 4칼럼 구조**: `Backlog` → `TODO` → `In-Progress` → `Done`
- **티켓 CRUD**: 생성, 조회, 수정, 삭제
- **드래그 앤 드롭**으로 칼럼 간 티켓 이동
- **일정 필드**: 계획 시작일, 실제 시작일, 계획 종료일, 실제 종료일

## 3. 2차 범위 (MVP 제외)

다음 항목은 2차 Spec으로 분리하며, MVP에는 포함하지 않습니다.

| 항목 | 비고 |
|---|---|
| 인증 (로그인/회원가입) | 단일 사용자 전제이므로 제외 |
| 커스텀 칼럼 | 4칼럼 고정 구조 유지 |
| 멀티 사용자 | 협업/공유 기능 미포함 |
| 라벨 / 코멘트 | 티켓 부가 정보 기능 미포함 |
| 파일 업로드 | 첨부파일 기능 미포함 |

## 4. 사용자 시나리오

1. 사용자가 새로운 할일을 **티켓으로 등록**한다 (Backlog에 생성)
2. 진행 상황에 따라 티켓을 **드래그 앤 드롭으로 상태 이동**시킨다 (TODO → In-Progress → Done)
3. 필요 시 티켓 내용을 **수정**하거나 **삭제**한다
4. Done 칼럼에서 **완료 여부를 확인**한다

## 5. 핵심 기능 목록 (Requirements.md 대응)

| ID | 기능명 | 설명 |
|---|---|---|
| FR-001 | 티켓 생성 | 사용자가 제목, 설명 등 정보를 입력해 새 티켓을 생성한다. 생성된 티켓은 기본적으로 Backlog 칼럼에 위치한다. |
| FR-002 | 티켓 조회 | 보드에 표시된 티켓을 클릭해 상세 정보(제목, 설명, 일정 등)를 확인할 수 있다. |
| FR-003 | 티켓 수정 | 기존 티켓의 제목, 설명, 일정 등 정보를 수정할 수 있다. |
| FR-004 | 티켓 삭제 | 더 이상 필요 없는 티켓을 보드에서 삭제할 수 있다. |
| FR-005 | 드래그 앤 드롭 상태 이동 | 티켓을 마우스(또는 터치)로 드래그하여 Backlog/TODO/In-Progress/Done 칼럼 간 이동시킬 수 있다. |
| FR-006 | 고정 4칼럼 보드 | 보드는 Backlog, TODO, In-Progress, Done 4개의 고정 칼럼으로 구성되며, 칼럼 추가/삭제/순서 변경은 지원하지 않는다. |
| FR-007 | 계획 일정 관리 | 티켓 생성/수정 시 계획 시작일(Planned Start)과 계획 종료일(Planned End)을 지정할 수 있다. |
| FR-008 | 실제 일정 기록 | 티켓이 In-Progress로 이동하면 실제 시작일(Actual Start)이, Done으로 이동하면 실제 종료일(Actual End)이 기록된다. |

## 7. 와이어프레임

전체 레이아웃은 **좌측 Backlog 사이드바 + 우측 3칼럼 보드(Swimlane)** 구조로 구성됩니다.

```
┌─────────────┬───────────────────────────────────────────────┐
│             │                    Tika Board                  │
│  Backlog    ├─────────────────┬─────────────────┬────────────┤
│  (Sidebar)  │      TODO       │   In-Progress    │    Done    │
│             │                 │                  │            │
│ ┌─────────┐ │  ┌───────────┐  │  ┌────────────┐  │ ┌────────┐ │
│ │ Ticket A│ │  │ Ticket C  │  │  │ Ticket E   │  │ │Ticket G│ │
│ └─────────┘ │  └───────────┘  │  └────────────┘  │ └────────┘ │
│ ┌─────────┐ │  ┌───────────┐  │                  │ ┌────────┐ │
│ │ Ticket B│ │  │ Ticket D  │  │                  │ │Ticket H│ │
│ └─────────┘ │  └───────────┘  │                  │ └────────┘ │
│             │                 │                  │            │
│ [+ 새 티켓] │                 │                  │            │
└─────────────┴─────────────────┴──────────────────┴────────────┘
```

- **좌측 사이드바 (Backlog)**: 아직 착수하지 않은 모든 티켓이 리스트 형태로 쌓이는 영역. 상단/하단에 새 티켓 추가 버튼 배치.
- **우측 3칼럼 보드**: TODO / In-Progress / Done 세 칼럼이 나란히 배치된 swimlane 형태. 사이드바의 티켓을 우측 보드로 드래그하면 TODO로 이동.
- 각 티켓 카드는 제목과 계획 일정(시작/종료)을 요약해서 표시하고, 클릭 시 상세 모달에서 전체 정보를 확인/수정 가능.
